# ReadWord - 中英翻译助手

一个功能强大的 iOS 应用，支持多种输入方式将中文翻译成英文，并提供发音功能。

## ✨ 功能特性

### 核心功能
- 🔤 **中文翻译英文**：使用 Apple Translation Framework 进行高质量翻译
- 🔊 **英文发音**：使用 AVSpeechSynthesizer 朗读翻译结果
- 📝 **历史记录**：自动保存最近的翻译记录

### 三种输入方式

#### 1. 📝 文字输入
- 直接输入或粘贴中文文本
- 支持多行文本输入
- 实时清空功能

#### 2. 🎤 语音输入
- 实时语音识别（Speech Framework）
- 支持中文普通话识别
- 可视化录音状态

#### 3. 📷 拍照/相册输入
- 拍照识别文字（OCR）
- 从相册选择图片识别
- 使用 Vision Framework 进行文字识别
- 支持简体和繁体中文

## 🛠 技术栈

### iOS 原生框架
| 功能 | 框架 | 说明 |
|------|------|------|
| 翻译 | Translation Framework | iOS 17.4+ |
| 发音 | AVFoundation (AVSpeechSynthesizer) | 文字转语音 |
| 语音识别 | Speech Framework | 中文语音识别 |
| 文字识别 | Vision Framework | OCR 图片文字识别 |
| 图片选择 | PhotosUI (PhotosPicker) | 相册选择 |
| 拍照 | UIKit (UIImagePickerController) | 相机拍照 |

### 架构设计
- **MVVM 架构**：清晰的代码组织
- **SwiftUI**：现代化的 UI 框架
- **Async/Await**：现代异步编程
- **Combine**：响应式编程

## 🚀 快速开始

### 系统要求
- iOS 17.4 或更高版本
- Xcode 15.0 或更高版本
- Swift 5.9 或更高版本

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/yourusername/ReadWord.git
cd ReadWord
```

2. **打开项目**
```bash
open ReadWord.xcodeproj
```

3. **运行项目**
- 选择目标设备或模拟器
- 点击运行按钮（⌘R）

### 权限说明

应用需要以下权限：
- 📷 **相机权限**：用于拍照识别文字
- 🎤 **麦克风权限**：用于语音识别
- 🖼 **相册权限**：用于选择图片识别文字
- 🗣 **语音识别权限**：用于将语音转换为文字

首次使用相关功能时，系统会自动请求权限。

## 📱 使用说明

### 文字输入模式
1. 点击顶部的"文字"按钮
2. 在输入框中输入中文
3. 点击"翻译"按钮
4. 查看翻译结果，点击喇叭图标可朗读

### 语音输入模式
1. 点击顶部的"语音"按钮
2. 点击"开始录音"按钮
3. 说出要翻译的中文
4. 点击"停止录音"
5. 识别结果会自动填入输入框
6. 点击"翻译"按钮获取翻译结果

### 拍照输入模式
1. 点击顶部的"拍照"按钮
2. 选择"拍照"或"相册"
   - **拍照**：打开相机拍摄包含中文的图片
   - **相册**：从相册中选择图片
3. 系统自动识别图片中的文字
4. 识别结果会自动填入输入框
5. 点击"翻译"按钮获取翻译结果

### 历史记录
- 应用会自动保存最近的翻译记录
- 点击历史记录可快速重新查看
- 最多保存 50 条记录

## 📝 注意事项

1. **Translation Framework 限制**
   - 需要 iOS 17.4 或更高版本
   - 首次使用需要下载语言包（需要网络）
   - 下载后支持离线翻译

2. **语音识别**
   - 需要安静的环境以获得最佳识别效果
   - 建议使用标准普通话
   - 首次使用需要网络连接

3. **OCR 识别**
   - 建议使用清晰的图片
   - 文字应该清晰可见
   - 支持简体和繁体中文
